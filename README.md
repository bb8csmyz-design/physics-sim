# 物理シミュレーション学習

高校物理〜大学入試レベルの現象を、パラメータを変えながら動かして確かめる学習用 Web アプリです。
グラフ・数式（KaTeX）・解説つき。スマホのホーム画面に追加でき、オフラインでも動きます（PWA）。

- 分野: 力学 / 熱 / 波動 / 電磁気 / 原子
- 実装済みの単元（ほかは順次追加）
  - 力学: 落下運動と放物運動（空気抵抗あり/なし） / 斜面上の運動と摩擦 / 剛体のつりあい /
    運動量保存と衝突 / 鉛直面内の円運動 / ばねの単振動 / 鉛直ばね振り子 / 単振り子 /
    万有引力とケプラーの法則 / 力学サンドボックス（物体・ばね・糸・斜面・滑車・壁を自由に配置。URL・JSON で保存）
  - 波動: 2 つの波源による干渉 / 弦と気柱の固有振動 / ドップラー効果 / 光の屈折と全反射 /
    レンズによる像 / ヤングの実験と回折格子
  - 電磁気: 等電位線と電気力線 / RC 回路の過渡現象 / 電場・磁場中の荷電粒子の運動 / 電磁誘導 /
    RL 回路の過渡現象 / 交流回路と RLC 共振 / 電気振動（LC 回路）
  - 熱: 気体分子運動論 / p-V 図と熱サイクル
  - 原子: 光電効果 / ボーアの水素原子模型 / 放射性崩壊と半減期

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # lint + 整形チェック + 型チェック + テスト
npm run build    # dist/ に本番ビルド
```

開発の規約（フォルダ構成・単元の追加手順・物理テストのルール・UI の統一ルール）は [CLAUDE.md](./CLAUDE.md) を参照。

## デプロイ（GitHub Pages）

`main` ブランチへの push で GitHub Actions がテストとビルドを行い、GitHub Pages に公開します。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
